# Ecommerce Performance Dashboard

## 1. Contexto

Este projeto apresenta um dashboard de e-commerce desenvolvido em Power BI para análise de performance comercial, comportamento de clientes e indicadores de risco.

## 2. Objetivo

Criar uma visão executiva para apoiar a tomada de decisão em vendas, retenção e acompanhamento de clientes.

## 3. Indicadores analisados

- Receita
- Pedidos
- Ticket médio
- Clientes
- Churn
- Devoluções
- Evolução temporal
- Segmentação por perfil de cliente

## 4. Páginas do relatório

### Performance de Vendas

Visão consolidada dos principais indicadores comerciais.

### Comportamento do Cliente

Análise de clientes por status, perfil e comportamento de compra.

### Comportamento de Risco

Análise de churn, devoluções e sinais de atenção operacional.

## 5. Ferramentas

- Power BI Desktop
- Modelagem de dados
- DAX
- Visualização de dados
